# Vete Sales Tracking

## Files

- `prospects.csv` — Master list of potential clinic customers

## Prospect Status Values

| Status | Description |
|--------|-------------|
| Not Contacted | New lead, no outreach yet |
| Contacted | Initial message sent |
| Responded | They replied (positive or negative) |
| Demo Scheduled | Meeting/demo booked |
| Demo Done | Demo completed |
| Trial | Using free trial |
| Negotiating | Discussing terms |
| Won | Paying customer 🎉 |
| Lost | Declined or no response |

## Priority Levels

- **High** (Score 80-100) — Large clinic, premium area, or warm lead
- **Medium** (Score 50-79) — Standard prospect with potential
- **Low** (Score <50) — Small clinic or long-shot

## Scoring Criteria

| Factor | Points | Description |
|--------|--------|-------------|
| Size: Large | +30 | 7+ vets, high volume |
| Size: Medium | +20 | 3-6 vets |
| Size: Small | +10 | 1-2 vets |
| Premium Location | +20 | Villa Morra, Carmelitas, Recoleta |
| Website Exists | +15 | Shows tech adoption |
| Instagram Active | +10 | Marketing-conscious |
| Near San Lorenzo | +15 | Easy demos/support |
| Warm Intro | +25 | Personal connection |

## How to Use

1. Add new prospects to `prospects.csv`
2. Update Status and Last Contact after each touchpoint
3. Set Next Action for follow-up
4. Review weekly to ensure follow-ups happen
